A tiny stack virtual machine (Node 22, no dependencies): 32-bit wrapping integers, a 256-value stack, a 64-deep call stack, 256 words of memory, byte input/output, and all eleven traps from ISA.md v1. One run answers every instance in the input dir.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=<input> MAKEFUN_OUTPUT_DIR=out node main.ts
```
